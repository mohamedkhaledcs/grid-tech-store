# Tech Store

A responsive tech products landing page built using **HTML and CSS**.

## Features

- Fixed navigation bar
- Full-screen hero section
- Animated changing text
- Responsive product grid
- Different product card layouts
- Hover effects and animations
- About section
- Contact form
- Footer with social links
- Responsive design for desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Animations
- Media Queries

## Responsive Design

The website adapts to different screen sizes using media queries.

- Desktop
- Tablet
- Mobile
